# Pet packs

Each folder here is one pet. Make your own by copying a folder, swapping the
images, and editing `manifest.json`.

```json
{
  "id": "panda",
  "name": "Panda",
  "author": "you",
  "license": "CC-BY-4.0",
  "width": 128,
  "height": 128,
  "facing": "right",
  "animations": {
    "idle": { "fps": 3, "frames": ["idle-0.png", "idle-1.png"] },
    "walk": { "fps": 6, "frames": ["walk-0.png", "walk-1.png", "walk-2.png"] }
  }
}
```

| Field | Meaning |
|---|---|
| `id` | Unique, `a-z 0-9 - _`. A user pack with the same id as a built-in replaces it. |
| `width`, `height` | Display size in pixels at size 1.0× (16–1024). Frames are scaled to fit, bottom-aligned. |
| `facing` | Which way the art faces: `right`, `left`, or `none` (never mirrored). |
| `animations` | Name → `{ fps, frames }`. `fps` 0.5–60 (default 6). Frames are files in this folder: `.png .gif .webp .jpg .svg`. |

## Animation names

Only **`idle`** is required. Anything missing falls back:

| Animation | Used when | Falls back to |
|---|---|---|
| `idle` | standing around | (required) |
| `walk` | walking | `idle` |
| `sit` | sitting | `idle` |
| `sleep` | napping | `sit` |
| `happy` | petted, hopping, happy mood | `idle` |
| `sad` | sad mood | `idle` |
| `bored` | bored mood | `sit` |
| `surprised` | woken up, landing after a drop | `happy` |
| `drag` | being carried / falling | `surprised` |
| `alert` | a reminder is due | `happy` |
| `eat` | being fed | `happy` |
| `play` | playing | `happy` |
| `sweat` | the computer is under heavy load | `sad` |
| `hungry` | hungry (care mode) | `sad` |

## Built-in packs

- `panda/` and `cat/` (Ginger Cat): generated by `node tools/gen-pets.mjs`
  with every animation. Edit that script and re-run it to change the art.
- `blue-cat/`: the walk cycle from the original C++ version. It only has
  `walk` frames, so every other state shows a still frame.
